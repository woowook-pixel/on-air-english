# Script 적용 기준

공통 기준은 `DESIGN.md`, 토큰은 `tokens.css`를 따른다. 이 문서는 Script(구 On Air)에만 해당하는 내용이다.

## 앱 이름

- 표시 이름: "On Air" → `Script`
- 상단 바 워드마크: `SCRIPT`
- HTML `<title>`, manifest(있다면) `name`, `short_name`도 Script로 변경

## 구조 변경 (아이팟 스킨 제거)

아이팟 본체, 화면 테두리, 클릭휠, 배터리 표시를 모두 없애고 공통 화면 골격으로 바꾼다. 기존 메뉴 6개는 아래처럼 옮긴다. 기능은 하나도 없어지지 않아야 한다.

| 기존 메뉴 | 옮길 위치 |
|---|---|
| 뉴스 듣기 | 하단 탭 "듣기" |
| 기사 읽기 | 하단 탭 "읽기" |
| 지난 목록 | 하단 탭 "보관함" 안의 밑줄 탭 "지난 목록" |
| 저장함 | 하단 탭 "보관함" 안의 밑줄 탭 "저장함" |
| 지금 재생 중 | 탭바 바로 위 고정 미니 플레이어(재생 중일 때만), 누르면 재생 화면 |
| 설정 | 상단 바 텍스트 버튼 "설정" |

클릭휠 조작은 버튼으로 옮긴다.

| 기존 조작 | 변경 |
|---|---|
| 휠 돌리기(5초 이동) | 텍스트 버튼 "−5", "+5" |
| 휠 ◀◀ ▶▶ (15초 이동) | 텍스트 버튼 "−15", "+15" |
| ▶▶ 길게 누르기(다음 방송) | 목록 행 "다음 방송 →" |
| 가운데 버튼, ▶II | 검정 사각 "PLAY" / "STOP" |
| MENU | 상단 바 텍스트 버튼 "← 목록" |

## 화면별 변경

### 듣기 (탭 1)

| 영역 | 변경 |
|---|---|
| 상단 바 | 왼쪽 `SCRIPT`, 오른쪽 "설정" |
| 제목 | 보조 라벨 "오늘의 방송 N개"(실제 개수) + 44px 제목 "뉴스 듣기" |
| 목록 | 섹션 라벨 "음성" + 목록 행: 방송 제목(16 / 500, 한 줄 말줄임) + 보조줄 프로그램명, 오른쪽 "→" |

### 읽기 (탭 2)

| 영역 | 변경 |
|---|---|
| 제목 | 보조 라벨 "오늘의 헤드라인" + 44px 제목 "기사 읽기" |
| 목록 | 섹션 라벨 "글" + 목록 행: 기사 제목 + 보조줄 출처, 오른쪽 "→" |

### 보관함 (탭 3)

| 영역 | 변경 |
|---|---|
| 제목 | 44px 제목 "보관함" |
| 전환 | 밑줄 탭: 지난 목록 / 저장함 |
| 목록 | 같은 목록 행 형태. 비어 있으면 공통 빈 상태(검은 선 아래 "아직 없습니다.") |

### 재생 화면

| 영역 | 현재 | 변경 |
|---|---|---|
| 상단 | 아이팟 화면 제목줄 "음성 뉴스", ▶ 표시, 배터리 | 상단 바: 왼쪽 `SCRIPT`, 오른쪽 "← 목록" |
| 썸네일 | 둥근 모서리 사진 | 96px 정사각, 모서리 없음, 흑백 |
| 정보 | 주황 "음성" 배지 + 프로그램명 | 보조 라벨: Ember 점 + "음성", 아래 Gray 프로그램명 · 출처 |
| 제목 | 굵은 방송 제목 | 32px 900, 여러 줄 허용 |
| 진행 | 둥근 진행 막대, 0:00 / -0:00 | 2px Line 색 선 + 현재 위치 Ember 세로 막대(4×12px), 아래 시간 12px 700 |
| 조작 | 클릭휠 | 한 줄: "−15" "−5" [PLAY] "+5" "+15" |
| 안내 | 휠 사용법 문구 | 삭제 |
| 하단 | "원문 열기 (BBC) ↗", 파란 하이라이트 "☆ 저장" | 목록 행 3개: "다음 방송 →", "원문 열기 (출처) ↗", "☆ 저장"(저장됨이면 "★ 저장됨") |

### 미니 플레이어

- 탭바 바로 위 고정, 흰 바탕, 위쪽 Line 1px 선
- 왼쪽 Ember 점, "NOW PLAYING" 10px 800 라벨 + 방송 제목 한 줄, 오른쪽 텍스트 버튼 "PLAY" / "STOP"

### 설정

- 시안 없음. 공통 골격(제목 + 섹션 라벨 + 목록 행)으로 맞추고, 판단이 애매하면 바꾸지 말고 보고한다.

## Ember 사용 위치 (Script)

- 지금 재생 중인 것: 미니 플레이어 점, 재생 화면 진행 위치, 재생 화면 "음성" 라벨 점.

- 아이팟 스킨을 옵션으로 남기지 않는다.
